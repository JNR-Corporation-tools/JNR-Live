Live Server
A fast cross-platform developer utility that connects the real VS Code Live Server with devices on your local network.
DeveloperRaj VermaVersion 2.1.0

        
ARCHITECTURE
Purpose-built gateway
FastAPI + Uvicorn management, authenticated reverse proxying, WebSocket forwarding, QR pairing, session controls and watchdog-based reload notifications.
PRINCIPLES
Secure by default
It does not become a generic LAN file server, does not expose the laptop filesystem and does not pretend a private LAN URL is internet-accessible.
BRAND
JNR Corporations
Designed and developed by Raj Verma for Windows and Linux local web development workflows.
